# 🧱 [pNr.HnS] — Plugins

Repositório oficial destinado à publicação gratuita dos plugins personalizados desenvolvidos para servidores de **HideNSeek** para **Counter-Strike 1.6** e **Counter-Strike: Global Offensive**.

O principal objetivo deste projeto é disponibilizar plugins e seus respectivos códigos-fonte para a comunidade, permitindo que outros servidores e desenvolvedores possam utilizar, estudar, modificar e adaptar os recursos de acordo com suas necessidades.

# 🇧🇷 Português

## 🎯 Objetivo

A proposta da **[pNr.HnS]** é simples:

> Compartilhar gratuitamente plugins personalizados desenvolvidos para servidores de HideNSeek.

Este repositório busca preservar e disponibilizar projetos desenvolvidos ao longo do tempo para a comunidade de HNS, evitando que esses códigos fiquem restritos a um único servidor.

Entre os projetos disponibilizados, o principal destaque são os **Blockmakers personalizados**, desenvolvidos para diferentes versões do Counter-Strike.

## 🧱 Blockmaker

Os Blockmakers são um dos principais conteúdos deste repositório.

Serão disponibilizadas versões e projetos personalizados de Blockmaker para:

- **Counter-Strike 1.6** — arquivos `.sma`
- **Counter-Strike: Global Offensive** — arquivos `.sp`

Os projetos podem conter funcionalidades, blocos, comandos e sistemas desenvolvidos especificamente para a experiência de HideNSeek da **[pNr.HnS]**.

### Counter-Strike 1.6 — BCM4

Além dos Blockmakers, este repositório também disponibiliza outros plugins personalizados para o modo **HideNSeek**, desenvolvidos para melhorar, expandir ou adicionar funcionalidades aos servidores.

Os plugins podem ser utilizados separadamente ou em conjunto, dependendo de suas dependências e funcionalidades.
